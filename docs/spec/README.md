# Specar

Varje funktion får en egen spec innan den byggs. Specen innehåller:

- **Vad och för vem:** vilket behov (B1–B6) funktionen löser.
- **Acceptanskriterier:** "Klart när …". Varje kriterium blir ett test.
- **Kantfall:** saknad data, fel filformat, glapp i tiden med mera.
- **Inte med:** det som medvetet lämnas utanför.

Varje spec delas sedan upp i issues på GitHub, på 20–45 minuter var.
